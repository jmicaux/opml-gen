# Changelog

All notable changes to OPML Generator are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-07-26

### Added
- Static rebuild of the old `opml-gen.ovh` page.
- Generate a valid OPML 2.0 file in the browser from a list of RSS feed URLs.
- Copy-to-clipboard and download of the generated file; all input is XML-escaped.
- Live-preview page, project badges and documentation.
